# Rainbow Park — prueba de propuestas

Copia de la vista previa actual: propuestas A (Editorial), B (Salón) C (Atlas) y D (Experiencia), referencia original, selector de colores Champaña/Azul noche y vistas de escritorio, laptop y teléfono.

## Publicar en Vercel

Importa este repositorio y selecciona la rama `main`. Usa la raíz del repositorio como Root Directory y el preset **Other**. `vercel.json` configura el directorio `public`, sin instalación ni compilación. No necesita una base de datos.

La portada es el comparador. Para abrir la combinación A + C en champaña: `/?version=c&palette=champagne&section=inicio`.

Se incluyen videos, fotografías, modelos 3D, documentos y bibliotecas locales. Algunos servicios de mapas y tipografías requieren conexión a Internet. El formulario conserva su comportamiento actual: descarga la consulta; no envía mensajes.

Esta es una copia para revisión. No modifica la web publicada de Rainbow Park.

## Cuarta propuesta

D conserva el diseño del chat «Diseñar experiencia web Rainbow Park». Incluye sus recursos locales y los modelos, planos, imágenes y datos del proyecto existente. Abre `/?version=d&palette=champagne&section=inicio`. La integración de recursos está registrada en `public/d/integration-assets.json`.
